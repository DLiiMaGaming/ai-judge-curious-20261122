Entry for the [make.fun bounty "Make the AI judge feel curious"](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311) (pot $50, 20 paid places).

`main.py` (Python 3.13, standard library only) writes one short text — 251 characters — to `/output/entry.txt`: a tin labelled sugar on a pantry shelf, a hundred folded notes inside, each in a different handwriting, each one starting with my name — and the twelfth note is dated tomorrow. One concrete scene, one twist, and a question left hanging whose answer feels close. The house AI judge compares entries two at a time and ranks them by how often it picks them.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
